# UI baseline — 2026-08-05

Контрольная фиксация интерфейса до начала редизайна «современный языковой тренер». Скриншоты собраны из debug APK на локальном эмуляторе `Pixel_6_API_36`.

## Environment

- Android emulator: API 36, `Pixel_6_API_36`.
- Compact viewport: 1080 × 2400 px at 420 dpi (примерно 411 dp по ширине).
- Expanded viewport: временно задано 1600 × 2400 px при той же плотности (примерно 610 dp по ширине), затем настройки эмулятора возвращены к исходным.
- Данные: встроенный каталог без пользовательских изменений, светлая тема; для теста также снята тёмная тема.

## Baseline observations

- В теме используется системная динамическая палитра, поэтому цвет и контраст зависят от устройства.
- Emoji выполняют роль брендовых и навигационных иконок; их внешний вид зависит от системного шрифта.
- Карточки курса, модуля, урока и слова почти не различаются по роли.
- Светлая и тёмная темы отображаются, но не имеют отдельной брендовой художественной настройки.

Эти изображения — контрольная точка для ручного сравнения после каждой вертикальной итерации. Они не являются требованиями к новому интерфейсу.
