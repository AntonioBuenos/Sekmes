# Визуальные карточки: партия 04

Четвёртая партия содержит 50 существительных, проверенных на наличие в словаре, уникальность и визуальную однозначность.

## Правило для людей

Люди в медицинских, профессиональных и общественных сценах выполняются в согласованном канадском cut-paper-образе: голова состоит из двух крупных горизонтальных половин с заметным тёмным промежутком, глаза точечные, тело геометрически простое. Тёмный промежуток сам является ртом; нижняя половина лица остаётся пустой, без дополнительного нарисованного рта. Профессия или роль читается по действию, инструменту и окружению, а не по тексту. Существующие персонажи, костюмы и сцены не копируются.
