# Визуальные карточки: партия 03

Третья партия содержит 50 существительных, проверенных на наличие в словаре, уникальность и визуальную однозначность.

## Правило для зданий и мест

Главным объектом остаётся здание или место. Для масштаба и контекста разрешены одна-две небольшие второстепенные фигуры в согласованном канадском cut-paper-образе: голова из двух горизонтальных половин, точечные глаза и простое тело. Фигуры не должны перетягивать внимание с основного понятия.
