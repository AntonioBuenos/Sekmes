# Визуальные карточки: партия 02

Вторая партия содержит 50 вручную проверенных конкретных существительных.

## Дополнение к art guide для людей

- оригинальный персонаж с явным визуальным сходством с канадцами из South Park: предельно простая блочная голова из двух широко разделённых горизонтальных половин, точечные глаза и примитивное тело;
- персонаж не превращается в анатомическую схему: он показывает пальцем на нужную часть своего тела;
- нужная часть полностью видна, но не увеличивается и не отделяется от персонажа;
- запрещено копировать конкретных персонажей, костюмы, лица и сцены South Park.
