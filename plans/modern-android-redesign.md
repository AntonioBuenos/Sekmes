# Plan: Современный Android-редизайн Sėkmės

- Status: completed
- Approved: 2026-08-05
- Updated: 2026-08-14 10:20 Europe/Vilnius

## Goal

Привести весь интерфейс Android-приложения Sėkmės к утверждённой концепции «современный языковой тренер»: сформировать узнаваемую литовскую айдентику, ясную информационную иерархию, постоянную навигационную основу и единообразные учебные сценарии, сохранив существующий офлайн-контент, данные пользователя и продуктовую логику.

## Scope

Включено:

- фирменная светлая и тёмная тема на основе глубокого зелёного цвета, сдержанного жёлтого акцента и нейтральных поверхностей;
- полная настройка Compose `ColorScheme`, `Typography`, `Shapes` и токенов отступов вместо шаблонной темы;
- замена emoji и текстовых стрелок на единый набор векторных Material Symbols/Material Icons с корректными accessibility-описаниями;
- общий адаптивный каркас приложения: нижняя навигация на компактных экранах и подходящее представление навигации на широких экранах;
- четыре верхнеуровневых раздела: «Главная», «Словарь», «Мои слова», «Ещё»; скрытие нижней навигации во вложенных учебных сценариях;
- редизайн главной, курсов, выбора тем, словарей, тестов, результатов, аудио, грамматики, Конституции, личных слов, статусов и настроек;
- компактные переиспользуемые компоненты для app bar, секций, карточек курса, строк действий, уроков, слов, фильтров, вариантов ответа, статусов, пустых состояний и диалогов;
- минимальное расширение DataStore для запоминания последнего открытого курса, чтобы блок «Продолжить обучение» был честным и устойчивым после перезапуска;
- исправление связанных с представлением UX-дефектов: числовой порядок уроков, обрезанные фильтры, неточные подписи прогресса теста и перегруженные действия статуса слова;
- адаптация под системный размер шрифта, светлую/тёмную тему, экраны телефонов и планшетов;
- обновление UI-тестов и визуальная проверка ключевых маршрутов на эмуляторе API 26+ и API 36.

Не включено:

- изменение учебных материалов, переводов, аудиофайлов или структуры каталогов;
- изменение алгоритма подбора вариантов теста и семантики типов слов;
- аккаунты, облачная синхронизация, социальные функции, серии дней, очки и другая геймификация;
- архитектурная миграция приложения на новый слой ViewModel/domain или замена Navigation Compose;
- переработка Room-схемы, кроме случаев, когда без неё обнаружится ранее существовавший дефект данных;
- изменение Media3/ExoPlayer и механики офлайн-воспроизведения, не связанное с UI.

## Design decisions

- Основное направление: спокойный взрослый «современный языковой тренер», без детской геймификации.
- Основной цвет: глубокий литовский зелёный; жёлтый используется дозированно для прогресса и позитивного акцента; красный — для ошибок и опасных действий.
- Dynamic Colors не определяют внешний вид приложения по умолчанию: брендовая схема должна быть стабильной на всех устройствах. Возможность системной палитры может быть добавлена позже отдельной настройкой.
- Типографика остаётся системной для хорошей поддержки русского и литовского, но получает полную шкалу размеров, высот строк и насыщенностей.
- Основная навигация на телефоне: «Главная», «Словарь», «Мои слова», «Ещё».
- Грамматика и Конституция остаются доступны с главной через быстрые действия и из раздела «Ещё».
- На экране словаря отображается один текущий статус; изменение статуса выполняется через чип или компактное меню вместо трёх постоянных текстовых кнопок.
- До выбора ответа варианты теста нейтральные; цвет используется только для выбранного, правильного и неправильного состояния.
- Контент не растягивается бесконтрольно на планшетах: используются ограничение ширины и адаптивная навигация.

## Success criteria

- [x] На пользовательских экранах не осталось emoji-иконок и текстовых стрелок, используемых как элементы управления.
- [x] Светлая и тёмная темы имеют собственные проверенные брендовые схемы и не зависят от обоев устройства.
- [x] Все экраны используют согласованные токены цвета, типографики, формы и отступов; случайные локальные размеры сведены к обоснованным исключениям.
- [x] На компактном экране доступны четыре утверждённых верхнеуровневых раздела, а нижняя навигация не показывается во вложенных сценариях.
- [x] Главная показывает курсы как основной контент, блок продолжения обучения и компактные быстрые действия.
- [x] Последний открытый курс корректно восстанавливается после перезапуска; при отсутствии истории используется детерминированный fallback.
- [x] Темы курса отображаются в естественном числовом порядке (`1, 2, 3 … 10, 11, 12`).
- [x] Поиск и фильтры словаря не обрезаются на ширине 360 dp и при увеличенном системном шрифте.
- [x] Карточки/строки слов не содержат три конкурирующих действия статуса; изменение статуса остаётся доступным не более чем за два нажатия.
- [x] Тест показывает точный прогресс «Вопрос N из M», нейтральные варианты до выбора и доступные состояния результата после ответа.
- [x] Главные сценарии доступны в светлой и тёмной теме на компактной и расширенной ширине без горизонтального переполнения и обрезанного текста.
- [x] Все интерактивные элементы имеют область нажатия не меньше 48 dp, корректные semantics/content descriptions и не кодируют смысл только цветом.
- [x] Существующие данные, словари, статусы, пользовательские слова, настройки и воспроизведение аудио продолжают работать без потерь.
- [x] `testDebugUnitTest`, `assembleDebug` и `lintDebug` проходят; `connectedDebugAndroidTest` проходит на доступном эмуляторе/устройстве.
- [x] Ключевые маршруты визуально проверены на эмуляторе: главная, курс, темы, словарь, тест, результат, аудио, грамматика, Конституция, «Мои слова», «Ещё» и настройки.

## Delivery sequence

Реализацию следует вести вертикальными проверяемыми итерациями:

1. **Foundation:** шаги 1–4 — тема, компоненты и навигационный каркас.
2. **Core learning loop:** шаги 5–8 — главная, курс, словарь, тест и результат.
3. **Supporting modules:** шаги 9–11 — аудио, грамматика, Конституция, личные слова и настройки.
4. **Quality pass:** шаги 12–13 — адаптивность, accessibility, тесты и финальная регрессия.

После каждой итерации приложение должно оставаться собираемым и пригодным для ручной проверки. Массовая параллельная перепись всех экранов без промежуточной интеграции не допускается.
