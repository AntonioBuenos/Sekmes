# Plan: Учебный модуль «Конституция Литовской Республики»

- Status: in_progress
- Approved: 2026-07-25
- Updated: 2026-07-25 17:55 Europe/Vilnius

## Goal

Добавить в Android-приложение Sekmes второй учебный модуль для изучения Конституции Литовской Республики: 11 тематических блоков, последовательное чтение параллельного литовско-русского текста, общий словарь терминов и тесты по блокам и всему модулю.

## Scope

Включено:

- импорт исправленного параллельного текста `constitution_lt_ru_parallel(1).md` в проверяемый JSON-ресурс приложения;
- разбиение материала на 11 утверждённых блоков: преамбула и статьи 1–154;
- десять связанных частей преамбулы;
- отдельные части для всех встроенных нумерованных перечней с сохранением номера исходной статьи;
- литовский текст как основной, русский непосредственно под ним и переключатель скрытия перевода;
- подсветка сроков, чисел, дат и долей;
- связывание ключевых терминов с общим словарём;
- добавление 100 терминов Конституции в общий каталог с безопасным повторным использованием точных существующих словарных записей;
- словарь и тесты по каждому блоку и по всей Конституции;
- навигация между Sėkmės и Конституцией без перехода на Navigation Compose или ViewModel;
- автоматические проверки импортируемых данных, репозитория и ключевых UI-сценариев.

Не включено:

- удалённая загрузка или синхронизация материалов;
- аудиоверсия Конституции;
- интервальное повторение сверх уже существующих статусов слов;
- изменение существующих материалов Sėkmės, кроме обобщения навигации и словаря/тестов для выбора курса.

## Success criteria

- [x] В приложении есть отдельный модуль «Конституция» с 11 блоками, охватывающими преамбулу и статьи 1–154 ровно один раз.
- [x] Экран блока показывает название, краткое описание, диапазон статей, перечень статей и действия словаря и теста.
- [x] Экран статьи показывает литовские смысловые карточки, русский текст непосредственно под ними и сохраняемый при пересоздании переключатель перевода.
- [x] Преамбула отображается десятью связанными карточками.
- [x] Встроенные нумерованные перечни, включая статьи 67 и 84, отображаются пунктами при сохранении номера статьи.
- [x] Термины в тексте открывают правильную общую словарную запись; числа, даты, сроки и доли визуально отличимы.
- [x] Сто терминов Конституции доступны в словаре и тестах; точные совпадения переиспользуют существующие `wordId`, неоднозначные не объединяются автоматически.
- [x] Статусы `KNOWN`, `LEARNING` и `HARD` работают для терминов Конституции так же, как для Sėkmės.
- [x] Импорт и каталог проверяют полноту статей, уникальность частей, ссылки на термины и согласованность перечней.
- [x] `testDebugUnitTest`, `assembleDebug` и `lintDebug` проходят; UI проверен на доступном API 26+ эмуляторе или устройстве.

## Decisions and blockers

- Источником текста служит исправленный файл `C:/Users/watas/Downloads/constitution_lt_ru_parallel(1).md`; предыдущий вариант не используется для импорта.
- Базовый текст приложения хранится в JSON-ресурсе, а Markdown остаётся исходником для воспроизводимого импорта.
- Преамбула сегментируется десятью явно заданными парами, потому что в таблице литовская часть изначально объединена в одну строку.
- Перечни разбираются обобщённо по нумерованным пунктам, не только для статей 67 и 84.
- Совпадения словарных статей объединяются только при точном совпадении литовского текста, русского перевода и типа слова; `mokestis` и `darbas` остаются разными записями из-за различающейся семантики перевода.
- Для литовских словоформ используются явные, проверяемые surface-формы и отчёт по неоднозначным/ненайденным ссылкам; эвристическое сопоставление по корню не применяется.
- Подключённого API 26+ устройства или эмулятора нет. Android-test APK собран; инструментальные тесты готовы к запуску при появлении устройства.
