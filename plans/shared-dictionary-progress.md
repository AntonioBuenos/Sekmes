# Plan: Общий словарь и пользовательский прогресс

- Status: completed
- Approved: 2026-07-25
- Updated: 2026-07-25 13:47 Europe/Vilnius

## Goal

Подготовить словарную часть Sekmes к добавлению других учебников: вынести слова в единый каталог со стабильными идентификаторами, связать уроки разных курсов со словарными статьями по ссылкам и добавить сохраняемые пользовательские статусы слов, влияющие на словарь и тестирование.

## Scope

В работу входят:

- единый каталог слов со стабильными `wordId`, не зависящими от написания, перевода или позиции в списке;
- модели курса, урока и связи урока со словарной статьёй;
- перенос текущих данных Sekmes из вложенных списков слов в общий каталог и ссылки уроков;
- отчёт о точных дубликатах и неоднозначных совпадениях перед объединением данных;
- версионируемые JSON-файлы для каталога и учебных материалов;
- индексы для доступа к словам по ID и уроку, а при необходимости — по нормализованному литовскому и русскому написанию;
- сохранение пользовательского прогресса в Room;
- статусы `NEW`, `LEARNING`, `HARD`, `KNOWN`;
- управление статусами из словаря и теста;
- исключение `KNOWN` из тестов и стандартного представления словаря с возможностью показать и вернуть известные слова;
- повышенный приоритет `HARD` в тестах без немедленных повторов одного слова;
- проверка архитектуры на втором тестовом курсе, переиспользующем часть общего словаря;
- автоматические тесты, сборка, lint и проверка основных пользовательских сценариев;
- выполнение работы в отдельной ветке `codex/` от актуальной `development`, commit, push, merge request в `development` и merge после успешных проверок.

В текущий объём не входят:

- полноценный алгоритм интервального повторения; первая версия использует управляемую взвешенную выборку;
- загрузка учебников с сервера и удалённая синхронизация прогресса;
- разделение приложения на несколько Gradle-модулей без подтверждённой необходимости;
- автоматическое объединение слов с одинаковым написанием, но разными значениями.

## Success criteria

- [x] Каждая словарная статья имеет уникальный постоянный `wordId`, не вычисляемый из отображаемого текста или индекса списка.
- [x] Уроки Sekmes содержат ссылки на общий словарь, а не дублирующиеся объекты слов.
- [x] После миграции сохранены состав, порядок и количество слов каждого текущего урока.
- [x] Все ссылки уроков разрешаются в существующие словарные статьи; потерянных и дублирующихся ID нет.
- [x] Точное повторение одной словарной статьи в разных уроках использует один `wordId`, а разные значения не объединяются автоматически.
- [x] Пользовательские статусы сохраняются после перезапуска приложения и применяются во всех курсах.
- [x] Слова `KNOWN` не появляются в тестах и скрыты в словаре по умолчанию, но доступны через фильтр и могут быть возвращены в изучение.
- [x] Слова `HARD` получают повышенный приоритет, не повторяются немедленно и не вытесняют полностью остальные доступные слова.
- [x] Второй тестовый курс может ссылаться на существующие словарные статьи без копирования их содержимого.
- [x] Unit-тесты, `testDebugUnitTest`, `assembleDebug` и `lintDebug` проходят; затронутые UI-сценарии проверены доступным способом.
- [x] Изменения закоммичены, отправлены в remote, оформлены merge request и влиты в `development` после успешных проверок.

## Decisions and blockers

- Утверждено: известные слова скрываются по умолчанию, но остаются доступными через фильтр.
- Утверждено: пользовательский статус слова глобален и действует во всех учебниках.
- Утверждено: одинаковое написание с разными значениями не объединяется автоматически.
- Утверждено: статический каталог и курсы хранятся отдельно от пользовательского состояния; для прогресса используется Room.
- Утверждено: первая версия повторения трудных слов использует взвешенную выборку, а не полноценный интервальный алгоритм.
- По аудиту безопасно объединяются только полностью одинаковые `lt + ru + type`; после такого объединения каталог содержит 1039 статей.
- Стабильные ID получают формат `word_000001` и назначаются один раз по порядку первого появления; редактирование текста и перестановка уроков ID не меняют.
- Нормализованная и начальная литовская форма используются только как поисковые индексы и сигналы ручной проверки, но не как идентичность статьи.
- В уроке 20 обнаружено литовское поле с кириллицей `žiūrėti телевизориў`; исправление текста не входит в аудит и не является блокером миграции.
- JSON-каталог хранится в `assets/content`; `index.json` перечисляет курсы, поэтому добавление учебника не требует изменения загрузчика.
- Репозиторий проверяет уникальность ID и целостность ссылок при загрузке, а также создаёт индексы по ID, нормализованному литовскому и русскому тексту.
- Прогресс хранится отдельно от каталога в Room-таблице `word_progress`; отсутствие строки означает состояние `NEW`.
- Room schema v1 сохраняет статус, счётчики ответов, серию, время последнего показа, следующего повторения и обновления.
- Для AGP 9 включён совместимый режим KSP `android.disallowKotlinSourceSets=false`; Gradle помечает настройку экспериментальной, но генерация Room-кода и сборка проходят.
- `connectedDebugAndroidTest` не запускался: на машине нет подключённого Android-устройства или запущенного эмулятора; APK тестов собран и готов к запуску.
- GitHub CLI 2.94.0 установлен в профиль пользователя; после повторной device-авторизации CLI успешно вошёл в GitHub как `AntonioBuenos`.
- Blockers: none.
