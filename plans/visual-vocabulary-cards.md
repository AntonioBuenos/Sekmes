# Plan: Визуальные карточки слов

- Status: blocked
- Approved: 2026-09-08
- Updated: 2026-09-19 21:24 +03:00

## Goal

Добавить взрослым русскоязычным пользователям визуальный режим изучения литовских слов, в котором одна словарная статья запоминается через выразительную и однозначную иллюстрацию в оригинальной эстетике взрослой cut-paper-сатиры.

## Scope

Включено:

- карточка соответствует одной существующей словарной статье и сохраняет её стабильный `wordId`;
- на карточке отображаются только иллюстрация и литовский вариант статьи;
- первая версия предназначена для свободного изучения, без теста, ввода ответа, переворота карточки и оценки знания;
- статьи включаются вручную по признаку визуальной однозначности, а не автоматически по части речи;
- первый набор формируется преимущественно из конкретных существительных: животные, люди и профессии, еда, одежда, предметы быта, транспорт, части тела, здания, места и природа;
- наглядные действия и признаки могут добавляться только после ручной проверки однозначности изображения;
- абстрактные понятия, служебные слова и неоднозначно изображаемые статьи исключаются из первой версии;
- визуальный язык: оригинальная грубая плоская бумажная аппликация, простые геометрические формы, неровный толстый контур и взрослая сатирическая интонация, без копирования существующих персонажей;
- изображения хранятся без встроенного текста; литовская подпись выводится средствами Compose;
- карточки доступны независимо от текущего статуса изучения слова.

Не включено:

- тестовый режим, проверка ответа и интервальные повторения;
- перевод, грамматическая справка, пример употребления и дополнительные подписи внутри карточки;
- автоматическая генерация изображений для всего словаря;
- карточки для предлогов, союзов, частиц, большинства местоимений, абстрактных существительных и неизобразимых глаголов;
- использование или копирование персонажей, логотипов и других узнаваемых элементов South Park.

## Success criteria

- [x] Для статьи можно явно указать наличие визуальной карточки и связанный графический ресурс без изменения `wordId`.
- [x] В первую подборку входят только вручную проверенные статьи с достаточно однозначной визуальной ассоциацией.
- [x] Экран карточки показывает одно изображение и литовский текст статьи; перевода и учебных контролов на карточке нет.
- [x] Литовский текст, включая диакритические знаки, рендерится Compose, а не является частью изображения.
- [x] Пользователь может последовательно просматривать карточки выбранной подборки.
- [x] Карточки доступны для изучения независимо от статуса `NEW`, `LEARNING`, `HARD` или `KNOWN`.
- [x] Иллюстрации выдержаны в согласованном оригинальном стиле и не воспроизводят существующих защищённых персонажей.
- [x] Каталог продолжает загружаться без карточек у большинства статей и без изменения существующих словарных и тестовых сценариев.
- [x] Изменение проходит пропорциональные unit-, build-, lint- и UI-проверки.

## Decisions and blockers

- Утверждено: целевая аудитория — взрослые пользователи с выраженной визуальной памятью.
- Утверждено: карточки являются режимом изучения, а не тестирования.
- Утверждено: единица карточки совпадает с отдельной статьёй существующего словаря.
- Утверждено: карточка содержит только изображение и литовский вариант статьи.
- Утверждено: обязательным критерием включения является полезность и однозначность картинки для конкретной статьи.
- Утверждено: начинать следует с вручную отобранных конкретных существительных; часть речи сама по себе не включает статью автоматически.
- Утверждено: изображения создаются без текста, а подпись накладывается интерфейсом приложения.
- Утверждено: настроение South Park передаётся через собственный cut-paper-язык без копирования персонажей и фирменных элементов.
- Точный размер первой подборки будет определён во время ручного отбора; массовая генерация всего каталога не входит в утверждённый объём.
- Реализация выполнена поверх текущей незавершённой ветки `codex/modern-android-redesign`, чтобы не потерять и не обходить уже изменённую навигацию и UI; посторонние пользовательские изменения сохранены.
- Для совместимости с minSdk 26 атрибут темы `android:windowLightNavigationBar` перенесён в ресурс `values-v27`; это устранило единственную lint-ошибку текущей рабочей копии.
- Blockers: none.

## Proposed plan changes

Запрошено расширение завершённого MVP до массовой, но поэтапной генерации карточек.

- Сформировать первую крупную партию только из вручную проверенных, визуально однозначных существительных существующего словаря.
- Для каждой статьи создать отдельную иллюстрацию без текста по утверждённому art guide, оптимизировать её в 768×768 WebP и добавить явную привязку к стабильному `wordId`.
- После партии проверить соответствие «статья → изображение», единообразие стиля, отсутствие текста/защищённых персонажей, размер APK и работу каталога/UI.
- Не включать автоматическую генерацию для всех 747 оставшихся существительных: грамматическая метка `n` сама по себе не гарантирует визуальную полезность.
- Предлагаемый размер первой партии — 50 новых карточек. При текущем среднем размере 97 КБ это добавит примерно 4,9 МБ ресурсов; варианты 25 и 100 добавят примерно 2,4 и 9,7 МБ соответственно.

Пользователь подтвердил первую партию из 50 новых карточек 2026-09-19. Изменение принято в объём работ.
